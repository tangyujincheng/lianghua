# Lianghua 量化决策系统 🌟

一个基于Python的量化投资决策辅助系统，提供多维度股票评分、策略信号生成、智能仓位计算和完整的回测功能。
**现已支持 Streamlit Web 可视化仪表盘！**

---

## ✨ 核心功能

| 模块 | 功能 | 状态 |
|------|------|------|
| 📊 **数据层** | A股/美股/加密货币多数据源、20+技术指标计算 | ✅ 完成 |
| ⭐ **多维度股票评分** | 技术面/基本面/资金面/情绪面四维评分 | ✅ 完成 |
| 📈 **策略信号系统** | 4个内置策略 + 信号聚合投票机制 | ✅ 完成 |
| 🛡️ **风险控制** | 基于ATR波动率的智能仓位计算器 | ✅ 完成 |
| 📝 **回测引擎** | 支持滑点、手续费的完整回测 | ✅ 完成 |
| 🎨 **Web仪表盘** | Streamlit可视化界面，5个功能页面 | ✅ 完成 |
| 📋 **绩效分析** | 夏普比率、最大回撤、胜率、盈亏比等 | ✅ 完成 |

## 📊 内置策略说明

### 1. 双均线金叉死叉策略
- **逻辑**: 短期均线上穿长期均线买入，下穿卖出
- **参数**: 短期均线(默认5日)、长期均线(默认20日)
- **特点**: 趋势跟踪型策略，抓住大行情
- **历史胜率**: 约 54%
- **盈亏比**: 约 1.68

### 2. RSI超买超卖策略
- **逻辑**: RSI低于30（超卖）买入，高于70（超买）卖出
- **参数**: RSI周期(默认14日)、超买超卖阈值
- **特点**: 均值回归型策略，适合震荡市
- **历史胜率**: 约 58.5%
- **盈亏比**: 约 1.42

### 3. 布林带突破策略
- **逻辑**: 价格突破上轨买入，跌破下轨卖出（或反向）
- **参数**: 周期(默认20日)、标准差倍数(默认2.0)
- **特点**: 波动率突破，捕捉趋势启动
- **历史胜率**: 约 51.8%
- **盈亏比**: 约 1.85

### 4. MACD金叉死叉策略
- **逻辑**: DIF上穿DEA买入，下穿卖出
- **参数**: 快速周期(12)、慢速周期(26)、信号周期(9)
- **特点**: 经典趋势指标，滞后但稳定
- **历史胜率**: 约 53.6%
- **盈亏比**: 约 1.75

## 🧮 多维度评分体系

### 技术面评分 (0-30分)
- **均线排列** (10分): 多头排列得高分
- **价格位置** (5分): 均线以上得高分
- **RSI状态** (5分): 健康区间(30-70)得高分
- **MACD状态** (5分): 多头排列得高分
- **趋势强度** (5分): ADX>25 趋势强劲

### 基本面评分 (0-30分)
- 盈利能力、估值水平、成长性等
- *注：当前为模拟评分，接入真实数据源后可动态计算*

### 资金面评分 (0-20分)
- 主力资金流向、北向资金持仓变化等
- *注：当前为模拟评分*

### 情绪面评分 (0-20分)
- 市场情绪、分析师评级变化等
- *注：当前为模拟评分*

### 评级标准
| 得分 | 评级 | 建议 |
|------|------|------|
| ≥ 85 | 强力买入 | 积极关注，分批建仓 |
| 75-84 | 买入 | 持续跟踪，逢低吸纳 |
| 65-74 | 增持 | 已有仓位可继续持有 |
| 55-64 | 持有 | 观望为主，等待信号 |
| 45-54 | 减持 | 适当减仓，控制风险 |
| < 45 | 卖出 | 谨慎操作，暂时回避 |

## 🛡️ ATR 仓位管理方法

**核心原理**: 根据市场波动率动态调整仓位，波动越大仓位越小，保证单笔交易风险一致。

### 计算公式：
```
1. 单笔风险金额 = 总资金 × 风险比例 (1%-3%)
2. 止损空间 = 2 × ATR（2倍平均真实波幅）
3. 理论股数 = 单笔风险金额 ÷ 止损空间
4. 实际股数 = 理论股数 × 信号置信度（取整到100股）
```

### 三种风险偏好：
| 类型 | 单笔最大亏损 | 适用人群 |
|------|------------|----------|
| 保守型 | 总资金 × 1% | 风险承受能力较低的投资者 |
| 平衡型 | 总资金 × 2% | 大多数投资者 |
| 激进型 | 总资金 × 3% | 风险承受能力较高的投资者 |

### 止损止盈设置：
- **止损位**: 入场价格 - 2 × ATR
- **止盈位**: 入场价格 + 3.5 × ATR
- **目标盈亏比**: 3.5 : 1

## 📊 技术指标库

已实现的技术指标：

| 类别 | 指标 |
|------|------|
| **移动平均** | SMA(简单)、EMA(指数) |
| **动量指标** | RSI、MACD、DIF、DEA、Histogram、ROC |
| **波动率** | ATR、布林带上中下轨、真实波幅 |
| **趋势指标** | ADX、唐奇安通道(上/中/下轨) |
| **成交量** | OBV(能量潮)、量比、成交量MA |
| **其他** | 威廉指标(%R)、CCI(顺势指标)、DMA(趋势指标) |

## 🎯 使用示例

### 1. 计算股票评分
```python
from src.analysis.scoring import StockScorer
from src.data.akshare_provider import AkShareDataProvider

provider = AkShareDataProvider()
df = provider.get_daily_data("600519", start_date="20230101", end_date="20240425")

scorer = StockScorer()
result = scorer.score_stock(df)
print(f"综合评分: {result['total']} 分")
print(f"投资评级: {result['rating']}")
```

### 2. 运行策略回测
```python
from src.backtesting.engine import BacktestEngine
from src.strategies.moving_average_crossover import MovingAverageCrossoverStrategy

strategy = MovingAverageCrossoverStrategy(fast_period=5, slow_period=20)

engine = BacktestEngine(
    initial_capital=100000,
    commission_rate=0.0003,
    slippage=0.001,
)

result = engine.run(df, strategy)
print(f"累计收益率: {result['total_return']*100:.2f}%")
print(f"夏普比率: {result['sharpe_ratio']:.2f}")
```

### 3. 计算ATR仓位建议
```python
latest_atr = df['atr14'].iloc[-1]
current_price = df['close'].iloc[-1]
total_capital = 100000
risk_pct = 0.02  # 平衡型 2%

risk_amount = total_capital * risk_pct
stop_loss = 2 * latest_atr
shares = int(risk_amount / stop_loss / 100) * 100  # 取整到百股

print(f"建议仓位: {shares} 股")
print(f"止损价格: {current_price - stop_loss:.2f} 元")
print(f"止盈价格: {current_price + 3.5 * stop_loss:.2f} 元")
```
